# 定时任务 Prompt 目录

本目录保存三个**已启用**定时研究任务的公开、可审阅执行 Prompt，维护研究逻辑与交付契约。所有时刻采用 `Asia/Shanghai`；实际定时触发由 ChatGPT 定时任务负责，GitHub 仓库不负责调度或直接发送邮件。

| 任务 | Prompt | 触发时间（北京时间） | 运行标识 |
| --- | --- | --- | --- |
| 每日市场与新闻联播简报 | [market.md](market.md) | 每天 08:00 / 12:00 / 20:00 | `MARKET-YYYY-MM-DD-HHMM` |
| 每日科技与论文情报 | [tech.md](tech.md) | 每天 08:00 | `TECH-YYYY-MM-DD-0800` |
| 中国研究媒体情报 | [china.md](china.md) | 每天 08:00 / 20:00 | `CHINA-YYYY-MM-DD-HHMM` |

## 加载顺序与单一事实来源

每次任务启动时：获取最新 `main` → 阅读根目录 `README.md`、`AGENTS.md` → 阅读本任务 `prompts/<agent>.md` → 执行研究与归档。根目录 `AGENTS.md` 为**所有任务共享的最高优先级归档、安全、并发及交付规范**；本目录仅定义各任务研究内容、分时逻辑、报告结构和针对性质量门禁。出现冲突，以 `AGENTS.md` 为准，并在运行结果中明确指出需要同步修订的文档。仓库 Prompt 不代替 ChatGPT 中的启用状态或定时器配置。

## 公开仓库隐私约定

这里保存的是当前定时任务 Prompt 的**结构化公开版**，不直接复制私有运行参数。真实收件人地址、授权账号、连接器凭据等只保留在定时任务的私有配置中，不得进入 Prompt、报告、manifest、索引及 Pages。各文件中的“原任务已授权收件人”表示继续使用对应任务既有私有收件人，不得根据公共仓库猜测或扩充地址。**没有实际完成上传、审计、Pages 验证和邮件验证时，不能声称交付成功。**

## 版本变更

修改本目录时，应同时检查 `AGENTS.md`、根目录 `README.md`、现有 ChatGPT 定时任务 Prompt 及测试/工作流是否同步；若修改调度，必须实际更新任务定时器，不得只改文档。严禁重新引入 Notion 归档环节；归档目标固定为 `reports/<agent>/YYYY/MM/DD/<RUN_KEY>/`。
